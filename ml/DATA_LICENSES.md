# Data licences and attribution (real-data set)

This file covers the **real** (non-synthetic) data DigiSim trains and evaluates on. Synthetic images are generated by code in this repository and carry no third-party licence. Nothing listed here is committed to git except small derived records (split manifest, hashes, our own labels); fetched images and converted datasets live under `ml/data_real/`, which is gitignored.

Not legal advice. Reviewed against the primary sources linked below on 2026-11-18.

## 1. CGHD - hand-drawn circuit diagrams (DFKI)

| | |
|---|---|
| What | Photographs of hand-drawn circuit diagrams with PASCAL VOC bounding boxes, rotation, text labels and polygons. We use a pilot of 4 drafters (`drafter_16`, `drafter_19`, `drafter_20`, `drafter_25`; 384 images), images and VOC annotations only. |
| Title | A Public Ground-Truth Dataset for Handwritten Circuit Diagram Images |
| Authors | Felix Thoma, Johannes Bayer, Yakun Li, Andreas Dengel (DFKI) |
| Primary source | Zenodo record 15333233, DOI [10.5281/zenodo.15333233](https://doi.org/10.5281/zenodo.15333233), version 15, 2025-05-03 |
| Fetched from | Hugging Face mirror `lowercaseonly/cghd`, pinned to revision `44a246d1dc41758ff46c26bd69dccd43d2055eba` (see `data_manifest.json`) |
| Licence we follow | **CC BY 4.0** - the licence on the Zenodo record, the primary source ([legal code](https://creativecommons.org/licenses/by/4.0/)) |
| Paper | F. Thoma, J. Bayer, Y. Li, A. Dengel, "A Public Ground-Truth Dataset for Handwritten Circuit Diagram Images", International Conference on Document Analysis and Recognition (ICDAR) 2021 Workshops, Springer, pp. 20-27 |

**The sources disagree about the licence.** Zenodo says CC BY 4.0. The Hugging Face mirror's metadata says `cc-by-3.0`, its README body says "Creative Commons Attribution Share Alike Licence 3.0" (CC BY-SA 3.0), and the GitHub repository `DFKI/cghd` ships a CC0 `LICENSE` file. We follow Zenodo (the dataset's primary record) and attribute. The most restrictive reading (BY-SA 3.0) would add a share-alike condition on adapted material. To stay compliant under either reading we do not redistribute the images, the converted labels or any CGHD-derived dataset; this repository only commits hashes, counts and our own relabelling decisions (`ml/real_data/labels/fet_polarity.json`). If the project ever publishes a dataset or a model card that bundles CGHD-derived material, resolve the licence with the CGHD authors first.

**Attribution text** (use it in the README, model card and any release that ships weights trained on this data):

> This work uses the CGHD dataset: F. Thoma, J. Bayer, Y. Li, A. Dengel, "A Public Ground-Truth Dataset for Handwritten Circuit Diagram Images", ICDAR 2021 Workshops, DOI 10.5281/zenodo.15333233, licensed under CC BY 4.0. We converted its VOC annotations to YOLO format, remapped classes to DigiSim's vocabulary and added NMOS/PMOS polarity labels to transistor symbols.

**Changes we made (CC BY requires saying so):** class remap to `ml/classes.yaml`; `transistor.fet` split into NMOS and PMOS by our own manual pass; `terminal`, `vss` and `voltage.dc` boxes triaged into input, output or supply ports (VDD/GND) from their neighbouring text, otherwise ignored; image EXIF orientation applied (removed from the converted copy); unmapped classes kept only as ignore regions.

## 2. Roboflow `my-first-project-yz9wf` (46 images, 6 gate classes)

| | |
|---|---|
| Source | Roboflow Universe, workspace `cirzer`, project `my-first-project-yz9wf`, https://universe.roboflow.com/cirzer/my-first-project-yz9wf |
| Export | Tracked in this repository as `My First Project.yolov8/` (and an identical `.zip`), exported 2026-06-15, no preprocessing or augmentation, 46 images |
| Licence | **CC BY 4.0** (stated in the export's `data.yaml`) |
| Attribution text | "Gate annotations: cirzer / my-first-project-yz9wf, Roboflow Universe, CC BY 4.0." |

The licence covers the annotations. Many source images look like figures from textbooks and Wikimedia-style diagrams and **may carry their own licences**; their provenance is undocumented. Use for training and evaluation only; **do not redistribute these images** as a public dataset. We convert the 7-point polygon labels to boxes and keep the existing train/valid/test split.

We did not use any Roboflow Universe downloads (they need a login). No Roboflow or Kaggle credentials are used anywhere in this pipeline.

## 3. `Sampleimages/` - 4 spare images with our labels

`Sampleimages/` holds the same 46 images as the Roboflow export (byte-identical, verified by SHA-256) plus 4 more that are not in the export: `eighth_iamge.jpg`, `fortythree_image.jpg`, `seventh_image.jpg`, `thirtythree_image.jpg`. Their provenance and licence are **undocumented** (`fortythree_image.jpg` looks like a phone photo of a hand drawing; the others look like web or textbook figures). We labelled them ourselves (`ml/real_data/labels/sample_labels.json`) and use them only as a held-out qualitative set (`heldout_qual`). Do not redistribute the images.

## 4. Third-party software that touches this data

- `ultralytics` (YOLOv8/YOLO11) is AGPL-3.0; weights trained with it are generally treated as derivative. See the README "Third-party model licences".
- `huggingface_hub`, Pillow, SciPy, NumPy are used by the ingestion scripts only (Apache-2.0 / HPND / BSD-3-Clause).
