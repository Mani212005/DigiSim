Conceptual Sketch & Blueprint Design System

An ultra-clean, technical drafting aesthetic for digital logic simulation. Features dark schematic grid lines, CAD-grade glyphs, sub-millisecond signal glow animations, and dockable technical inspectors.

💡 Core Design Directives
BLUEPRINT // CAD
  • Zero-Clutter Canvas: Deep navy drafting background with subtle 24px / 120px grid intersections.
  • Signal Physics Glow: Cyan (#00F0FF) for Logic HIGH, Slate (#1A3045) for Logic LOW.
  • Dockable HUD Inspectors: Replaces vertical clipping modals with crisp, bounded glassmorphic popovers.
  • YOLOv8 Vision OCR: Drag and drop hand-drawn sketches to auto-generate schematic wiring.
